# Ramona Terpstra Coaching - Vercel versie

Deze map bevat een statische versie van de conceptwebsite.

## Online zetten via Vercel

1. Ga naar https://vercel.com en log in.
2. Kies `Add New...` en daarna `Project`.
3. Upload of koppel deze map als project.
4. Laat de build-instellingen leeg of kies voor een statische site.
5. Publiceer de site.
6. Koppel daarna eventueel het domein `ramonaterpstra.nl` via de domeininstellingen van Vercel.

De startpagina is `index.html`. De styling staat in `styles.css`. De afbeeldingen staan in `images/`.
